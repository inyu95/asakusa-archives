# スポット写真

写真の一覧とメタデータはスプレッドシート「画像データ」が正です。`index.json` は使いません。

## 使い方

1. `web/assets/photos/<フォルダ名>/` に画像を置く（例: `凌雲閣/1.jpg`）
2. シート「画像データ」に行を追加する

| 列 | 内容 |
|---|---|
| フォルダパス | `assets/photos/凌雲閣` |
| データ名 | `1.jpg` |
| 写真タイトル / 説明 / 年代 / 作者… | 任意のメタ |

3. シート「マッピング」の `image` 列に同じフォルダ（例: `assets/photos/凌雲閣` または `凌雲閣`）を書く

情報パネルのギャラリーで ‹ › により複数枚を切り替え、各写真のタイトル・年代・作者などを表示します。
