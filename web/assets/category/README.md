# カテゴリアイコン

地図ピンに表示するアイコンです。山谷アーカイブと同様、カテゴリ名と同名の PNG を置きます。
ピンの色はスプレッドシート「カテゴリリスト」の B 列（color）です。

## 使い方

1. スプレッドシート「マッピング」の `category`（カテゴリ）列の値と同名のファイルを置く  
   例: カテゴリが `建築` → `web/assets/category/建築.png`
2. 「カテゴリリスト」でカテゴリ名（A 列）に対応する色を B 列に設定する（セルの塗りつぶし、または `#RRGGBB`）
3. 複数カテゴリはカンマ区切り（例: `建築,寺社`）。上から団子状に重なります
4. ファイルが無い／カテゴリ未設定のときは、名前の頭文字で代替表示します

拡張子は `.png` です。透明背景の正方形〜円形アイコンを推奨します。
